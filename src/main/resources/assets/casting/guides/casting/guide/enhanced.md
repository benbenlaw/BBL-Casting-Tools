# Enhanced

## Enhanced

Certain items have the "casting:enhanced" tag, this means they can be enhanced to a higher level in the modifier using the enhanced max level instead of the normal one. Enhanced items can be modified to the extreme, creating some insanely powerful tools and armor. The Omnithium tools and armor are examples of enhanced items, at base are better than netherite but allow for much higher modifications.
