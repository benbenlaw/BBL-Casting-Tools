# Modifiers

## Modifiers

There a large amount of modifiers that can be added to tools and armor. Searching for uses of modifier in JEI will show all modifiers available. Searching for uses of a tool or armor will show all modifiers that can be added to that item. Adding modifiers requires molten experience as well as either an item and or fluid depending on the modifier
