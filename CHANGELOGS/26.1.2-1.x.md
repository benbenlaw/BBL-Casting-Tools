# 1.7.1
- Overhauled the /tool command to respond better to inputs 

# 1.7.0 
- Added new tag "casting:enhanced" 
- Items with the Enhanced tag can be enhanced to a higher level in modifier
- Modifiers now take an additional field, max_enhanced_level, this is the max level for equipment tagged with the "casting:enhanced" tag
- With the addition of enhanced unbreaking 10 is no longer obtainable on un enhanced items
- Most modifiers levels have been tweaked to be more balanced with enhanced items
- Example change includes fortune max level dropping to 7 but enhanced fortune can go to 15
- Added Omnithium Ingot, Nugget, Block, Tools and Armor better than netherite and is part of the new "casting:enhanced" tag
- Added molten Omnithium
- Spears are now on the all melee weapon tag there may be issue let me know
- Fixed repairing recipe
- Fixed Soulbound translation

# 1.6.2

# 1.6.1
- Fixed Tool Modifier crashing if ingredient is empty

# 1.6.0
- Updated to NeoForge 26.1.2.21-beta
- Dropped support for Minecraft 26.1 and 26.1.1
- Migrated Excavation into the modifier instead of the event
- Buffed fortune to max level 7
- Torch Placer modifier now swings the players arm when used 
- Added Cobblestone Placer, same as torch but cobblestone instead
- Added Retaliation Modifier, when hit by a mob it has a chance to strike back at the mob with a configured amount of damage, this modifier only works on armor and the chance and damage can be configured in the modifier config
- Added Pulverizing Modifier, when breaking certain blocks will crush instead eg cobblestone to gravel does not work with excavation. This is a data map so you add a block and a loot table id example is in data/castingtools/data_maps/pulverizing_blocks.json,

# 1.3.1
- Added Magnet Modifier, collects items with a range of the player each level increase the range by 1 block, max level is 4, Tools only, can be changed in modifier config to work on armor as well but think could be a bit annoying to 
- Added Night Vision Modifier, give night vision for 250 ticks, after 250 ticks deals 1 damage to the helmet. Only for helmets, this cannot be changed any changed to valid items in modifier will not work
- Added Water Breathing Modifier
- Added Speed Modifier, valid for all armor, each piece of armor can have up to level 5, this stacks with other armor pieces
- Added Flight Modifier, valid for all armor, require only one piece to have this modifier to provide creative flight, should not interfere with other flight providing mods, but if it does please report it to me
- Added Soulbound Modifier, on death return the items to your inventory
- With this update these are the only modifiers that were in original casting that will be added. This means that Auto Smelt, Step Assist, Water Walker, Lava Walker, Feather Falling and Jets, will not be added (at least for now) as they were either underused or for a specific pack eg Jets for Contained.
- More specialized modifiers will be added in the future which could be more complex and have more unique effects but i think this is a good baseline to star with
- Fixed Unbreaking modifier using configs not data from the modifier itself
